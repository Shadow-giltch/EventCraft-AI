# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-10-31

### Added
- Complete GenAI-powered planning assistant core: Budget, Timeline, Vendor checklist, Personalized ideas.
- Multi-event support: Weddings (Indian & Global), Birthdays (Kids, Teen, Adult, Milestone), Community Events.
- Pure domain calculation engine: Largest-remainder decimal budget allocation with contingency lock.
- Lead-time proportional timeline scheduling with dependency order preservation and rush item flagging.
- Deterministic vendor checklist linking each category to budget lines and milestone book-by deadlines.
- Rule-based and GenAI personalization engine with cultural and logistical steer capabilities.
- Grounded assistant Q&A with server-side context reconstruction and prompt-injection defense.
- REST API powered by FastAPI, Pydantic v2 validation, RFC 7807 problem details, and strict security headers.
- Accessible, framework-free frontend adhering to WCAG 2.2 AA standards with high-contrast theming.
- Comprehensive test suite including unit, property-based, integration, security, and accessibility tests.
